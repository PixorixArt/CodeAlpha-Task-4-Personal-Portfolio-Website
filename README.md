# 🚀 CodeAlpha Task 4 — Personal Portfolio Website

A modern, responsive personal portfolio website built as the **4th and final task of my Front-End Development Internship at CodeAlpha**.

This project brings together the front-end skills and concepts I have been practicing throughout my internship, along with projects from my Software Engineering studies and personal JavaScript learning journey.

---

## 👩‍💻 About This Project

This portfolio represents my journey as a **Software Engineering student and Front-End Developer**.

I built it to showcase my:

* Front-end development skills
* Internship experience
* Personal and learning projects
* JavaScript practice
* Software Engineering journey
* Current goal of becoming a Full-Stack Developer

The website is designed with a dark developer-style interface, glassmorphism elements, responsive layouts, and interactive JavaScript features.

---

## ✨ Features

* 📱 Fully responsive design
* 🌙 Dark developer-style UI
* 💜 Neon/glowing visual effects
* 🪟 Glassmorphism cards
* 🧭 Responsive navigation bar
* 🍔 Mobile hamburger menu
* ⌨️ Typing animation
* ✨ Scroll reveal animations
* 🔗 Smooth scrolling navigation
* 📂 Project filtering
* 📩 Contact form validation
* ⬆️ Back-to-top button
* 📊 Skills and experience sections
* 📄 Resume download option
* 🔗 Links to GitHub, LinkedIn and other profiles

---

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling, responsive design and animations
* **JavaScript (ES6+)** — Interactivity and functionality

No frontend framework was required for this project. The website was built using **vanilla HTML, CSS and JavaScript**.
